# School Management UI

React + TypeScript + Vite. Başlatma ve gösterim adımları için [ana README](../README.md).

```bash
npm ci
npm run dev
npm run build
npm run lint
```

`/`: School Management, üç sekme. `/chat`: AI Chat.
Tüm veri ve fotoğraflar Vite `/api` proxy’si üzerinden Spring Boot’tan alınır.
